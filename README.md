# Text Emotion Detector

## Description

Text Emotion Detector is a simple Natural Language Processing application that identifies emotions from written text.

The application detects four basic emotions:

- Happy
- Sad
- Angry
- Fear

## Technology Used

- Python
- Natural Language Processing
- Keyword Matching

## Requirements

Python 3.x

## Installation

No external libraries are required.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python app.py

4. Enter a sentence.
5. The application displays the detected emotion.

## Example

### Input

I am very happy today.

### Output

Detected Emotion: Happy

## How It Works

The application compares words in the input sentence with predefined emotion keywords.

## Conclusion

This project demonstrates a simple Natural Language Processing technique for detecting emotions from text.
